This program writes one short, slow text to `entry.txt`: a whale moving through cold green water below a harbour, a hundred years along the same unhurried road, while the wind comes and goes above. It is a single quiet image meant to slow the reader down and leave something large and still behind after the last line.

## Run it

```sh
python3 main.py
```
